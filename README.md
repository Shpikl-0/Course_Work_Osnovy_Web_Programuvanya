TravelPlan
Веб-додаток для планування подорожей.
Технології

PHP 8.0 — серверна частина (MVC, без фреймворків)
MySQL — база даних
HTML / CSS / JavaScript — клієнтська частина
Leaflet.js — інтерактивна карта
OpenWeatherMap API — прогноз погоди

Запуск
Додаток працює у двох режимах:
Локально через XAMPP:
Розмістити папку travelplan у C:\xampp\htdocs\, запустити Apache і MySQL у XAMPP Control Panel, створити базу даних через phpMyAdmin (імпортувати config/database.sql), відкрити http://localhost/travelplan/public/.
На хостингу:
Додаток доступний за публічним посиланням, але лише при активному хостингу. Якщо сайт не відповідає — хостинг може бути тимчасово вимкнений.
